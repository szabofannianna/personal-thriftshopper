# Fake-material terms

When a wishlist item requires a real material, drop listings whose title or description contains any of these (case-insensitive, ignore accents). Also apply the item's own Exclude terms, translated into every search language.

## Fake fur, other fibres

| Need | Drop when listing says |
|---|---|
| Real wool / alpaca / cashmere, natural fibre | 100% acrylic, Acryl, akryl, akrylowy, acrilic, akril; blends where polyester or acrylic is the main fibre; treat "wool look", "Wolloptik", "effet laine" as fake |
| Real silk | satin polyester, satyna poliestrowa, "silk look", "Seidenoptik", "effet soie" |
| Real fur / shearling | faux fur, Kunstpelz, fausse fourrure, sztuczne futro, műszőrme, blană artificială, "teddy" fleece |

A term inside the seller's description ("not eco leather", "nie ekoskóra") is a negation, not a match — read the sentence before dropping.
